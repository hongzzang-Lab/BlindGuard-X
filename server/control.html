① 연결 확인

모두 초록이면 다음 단계로. 빨간 줄은 옆의 설명대로 하면 돼요.

카메라 확인 — 왼쪽이 횡단보도, 오른쪽이 대기구역을 보고 있어야 해요.

반대로 보이면 카메라 USB 두 개를 서로 바꿔 꽂고 Pi 프로그램을 다시 켜세요.

폰 경고 수신 시험 — 카메라 없이 폰 A로 주의 → 경고 → 긴급 → 해제를 2초 간격으로 보내요. 앱에서 '주행 시작'을 누른 뒤 하세요.

② Cam1 바닥 보정

카메라를 먼저 단단히 고정하세요 (보정 후 움직이면 다시 해야 함).
바닥에 테이프 점 6개 이상을 넓게 붙이고 줄자로 좌표를 잽니다. 연석선 위 = y 0, 인도 쪽 +, 차도 쪽 −, 횡단보도 가운데 = x 0 (인도를 왼쪽에 두고 바라보는 방향이 +x).

사진에서 테이프 점을 클릭 → 뜨는 창에 좌표 입력 (예: 0,-1.75). 검증용 점 2~3개도 따로 찍어 두면 정확도를 숫자로 볼 수 있어요.

점 0개

③ Cam2 대기구역

사진에서 대기구역(인도) 꼭짓점을 차례로 클릭 → '경계선 찍기'를 누르고 차도-인도 경계 양 끝 2점 클릭 → 적용.
적용하면 Cam2가 배경을 새로 배우니 5초 동안 구역을 비워 두세요.

구역 꼭짓점 0개 · 경계선 0/2

④ GPS 기준점

차량 역할 폰 A(앱 켜고 서버 연결)를 표시한 점에 내려놓고 버튼을 누르면 30초 동안 자동으로 기록해요. 두 점을 다 찍으면 자동으로 계산돼요. (하늘이 트인 곳에서)

폰 A GPS: -
⚪

폰 A를 출발점에 두고 30초 기록하면, 그 시각의 GPS 치우침을 빼 줘요.
