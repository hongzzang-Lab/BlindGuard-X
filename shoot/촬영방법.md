# 실물 Vision 성능 평가 촬영 방법

삼각대에 카메라를 한 대씩만 올릴 수 있어서 세션을 둘로 나눠 찍습니다.
어느 세션이든 **카메라 두 대를 모두 Pi에 꽂고 분석을 켠 채로** 찍습니다(Pi 한 대가 둘을 같이 돌리는 실제 조건).

| 세션 | 삼각대 | 나머지 카메라 | 보는 것 |
|---|---|---|---|
| 보정 | Cam1 (세션 1과 같은 자리) | Cam2 켜 둠 | Cam1 바닥 보정(H) |
| 세션 1 | Cam1 → 횡단보도(사람이 걷는 곳) | Cam2 켜 둠 | 검출률, ID 유지, 거리·속도, FPS·지연 |
| 세션 2 | Cam2 → 대기구역 | Cam1 켜 둠 | 출발 징후(EMR), 오경보, FPS·지연 |

삼각대에 없는 카메라는 빈 벽이 아니라 **사람이 보이는 쪽**을 향하게 고정하세요. 빈 화면이면 Pi가 덜 바빠져 FPS가 실제보다 좋게 나옵니다.

## 0. 준비 (한 번만)

노트북에서 촬영 파일을 Pi로 보냅니다. Pi 주소는 그날 네트워크에 맞게 바꾸세요.

```bash
cd <저장소 폴더>
scp -r shoot <Pi계정>@<PiIP>:~/realtest/
```

그다음은 모두 Pi에서 실행합니다.

```bash
ssh <Pi계정>@<PiIP>
cd ~/realtest
```

## 1. 보정 촬영 ("대략 몇 m"로 Cam1 바닥 보정)

Cam1을 삼각대에 올려 세션 1에서 쓸 자리·각도로 고정합니다. **이후 세션 1이 끝날 때까지 삼각대를 건드리지 않습니다.**

1. 촬영을 시작합니다.
   ```bash
   bash shoot/shoot.sh calib 보정
   ```
2. 한 사람이 아래 자리에 순서대로 가서 **자리마다 3초 이상 가만히** 서 있다가 다음 자리로 걸어갑니다. 기준은 삼각대 바로 아래 바닥이고, 좌우는 카메라가 보는 방향 기준입니다.

   | 순서 | 앞으로 | 좌우 |
   |---|---|---|
   | 1 | 3 m | 왼쪽 1.5 m |
   | 2 | 3 m | 오른쪽 1.5 m |
   | 3 | 6 m | 오른쪽 2 m |
   | 4 | 6 m | 왼쪽 2 m |
   | 5 | 9 m | 가운데 |

   거리는 걸음 수로 어림해도 됩니다(큰 걸음 한 번이 약 0.7~0.8 m). 장소에 맞게 바꿔도 되지만 **4곳 이상, 한 줄로만 서지 않기**(좌우로 벌리기), 발이 화면에 보이기를 지키세요.
3. `Ctrl+C`로 끝내고, 선 자리를 순서대로 "앞,오른쪽"으로 적어 실행합니다. 왼쪽은 음수입니다.
   ```bash
   python3 shoot/calib_distance.py --spots "3,-1.5  3,1.5  6,2  6,-2  9,0"
   ```
4. 화면에 자리별 오차가 나옵니다. 평균이 0.5 m 안쪽이면 충분합니다. 1 m 넘게 어긋난 자리가 있으면 순서나 좌우 부호를 확인하세요.
   - "구간 수와 자리 수가 다름"이 나오면 목록의 시간을 보고 `--pick 1,2,4,5,6`처럼 쓸 번호를 골라 다시 실행합니다.

이전 보정 파일은 `calib/H_cam1.json.bak_날짜`로 남습니다.

## 2. 세션 1 · Cam1 (횡단보도)

촬영마다 이름을 붙여 실행하고, 시작 후 5초는 화면 밖에 있다가 들어옵니다. 끝나면 `Ctrl+C`.

```bash
bash shoot/shoot.sh cam1 걷기_가까이
```

| 이름 | 하는 일 | 횟수 |
|---|---|---|
| `서기_3m` `서기_6m` `서기_9m` `서기_12m` | 그 거리에 15초 서 있기 (거리별 검출률) | 각 1번 |
| `걷기_가로` | 약 6 m 거리에서 화면을 좌→우, 우→좌로 보통 걸음 | 3번 |
| `걷기_멀어짐` | 3 m에서 12 m까지 걸어갔다 돌아오기 | 3번 |
| `빠르게` | 가로로 빠른 걸음·뛰기 | 3번 |
| `두명` | 두 사람이 서로 엇갈려 지나가기 (ID 유지) | 3번 |

거리별 서기는 화면에서 벗어나지 않고 계속 서 있어야 검출률이 의미가 있습니다.

## 3. 세션 2 · Cam2 (대기구역)

Cam2를 삼각대에 올려 대기구역을 비추게 합니다. **삼각대를 옮겼으면 대기구역 선을 다시 그려야 합니다.** 노트북 서버를 켜고 조작 페이지 ③ 탭에서 다시 클릭하세요(Pi는 `SERVER=ws://노트북IP:8000/edge bash shoot/shoot.sh cam2 구역확인`으로 연결).

```bash
bash shoot/shoot.sh cam2 출발
```

| 이름 | 하는 일 | 횟수 | 기대 |
|---|---|---|---|
| `출발` | 구역에 3초 서 있다가 경계선 쪽으로 걸어 나가기 | 5번 | 출발 징후·경계 넘음 |
| `급출발` | 서 있다가 갑자기 뛰어나가기 | 5번 | 출발 징후·경계 넘음 |
| `서성이기` | 구역 안에서 20초 서성이기만 (안 건넘) | 5번 | 징후 없음(오경보 확인) |
| `지나가기` | 경계선과 나란히 인도를 따라 지나가기 | 5번 | 징후 없음 |
| `돌아섬` | 경계선 앞까지 갔다가 돌아오기 | 3번 | 넘음 없음 |

한 촬영에 한 번씩만 하면 표에서 횟수 세기가 쉽습니다(`출발_1`, `출발_2`처럼 번호를 붙이세요).

## 4. 결과 정리

Pi에서 바로 표를 만듭니다.

```bash
python3 shoot/report.py
```

노트북으로 가져오려면 노트북에서 실행합니다(영상과 기록이 `realtest/pi_logs/`에 모입니다).

```bash
cd <저장소 폴더>
bash tools/sync_pi.sh <Pi계정>@<PiIP>
python3 shoot/report.py
```

촬영 하나마다 폴더가 하나 생깁니다: `logs/pi_날짜_시각_세션_이름/`

| 파일 | 내용 |
|---|---|
| `video/all_cam1_raw.avi`, `all_cam2_raw.avi` | 원본 영상 (다시 분석할 때 사용) |
| `video/all_cam1_overlay.avi`, `all_cam2_overlay.avi` | 분석 결과가 겹쳐진 영상 (발표용) |
| `cam1_frames.csv`, `cam1_tracks.csv`, `cam2_frames.csv` | 프레임별 기록 (FPS·지연·검출·위치·EMR) |

## 알아둘 점

- 이 보정은 어림한 거리로 만든 것이라, 표의 거리·속도는 **참고값**입니다. 검출률·ID 유지·FPS·지연은 보정과 상관없이 정확합니다.
- 보정을 촬영 뒤에 다시 해도 됩니다. `report.py`는 저장된 발 위치(픽셀)에서 지금 보정으로 거리·속도를 다시 계산합니다.
- "Cam2가 Cam1보다 몇 초 먼저 알아챘나"는 이 방식(카메라가 서로 다른 곳을 봄)으로는 잴 수 없습니다. 그 값은 CARLA 결과로 설명하세요.
- 노트북 관제 화면으로 같이 보려면 명령 앞에 `SERVER=ws://노트북IP:8000/edge`를 붙입니다. 안 붙이면 Pi 혼자 기록합니다.
